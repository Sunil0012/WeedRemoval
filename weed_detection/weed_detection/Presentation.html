Model Training & Hyperparameters

Training Setup

  • Base Model: YOLOv8n (COCO pretrained)
  • Epochs: 50
  • Batch Size: 16
  • Image Size: 640×640
  • Optimizer: AdamW
  • Initial LR: 0.001
  • Warmup: 3 epochs
  • Early Stopping: 20 epochs patience

Loss Functions

  • Box Loss (CIoU): Weight 7.5
  • Classification Loss (BCE): Weight 0.5
  • Distribution Focal Loss: Weight 1.5
  • Weight Decay: 0.0005
  • Mixed Precision: Enabled

Total Loss Function

L_total = 7.5 × L_box + 0.5 × L_cls + 1.5 × L_dfl
Training Results: Total loss decreased 65% over training period. Model achieved best performance at epoch 44-48 range before convergence.

3D Integration & Spatial Computing

3D Reconstruction Pipeline

2D Detection (bbox in pixels) ↓ Extract Depth Values ↓ Convert to 3D Coordinates: X = (x - cx) × d / fx Y = (y - cy) × d / fy Z = d ↓ Generate Point Cloud ↓ Estimate Object Pose (PCA)
